# Задание 22: Вычислительные процессы

## Общая информация

- **Тема:** параллельное и последовательное выполнение процессов, минимальное время завершения всей совокупности работ.
- **Формат данных:** таблица (файл `.ods` / `.xlsx`) с колонками: ID процесса, время выполнения (мс), ID процессов-предшественников (0 - если независимый).
- **Ответ:** минимальное время завершения всех процессов при оптимальном расписании.
- **Балл:** 1. **Время:** 8 мин.

---

## Правила

- Процессы **не приостанавливаются** - начавшийся процесс выполняется до конца.
- **Независимые** процессы (нет предшественников) могут выполняться **параллельно**.
- Если процесс B зависит от процесса A, то B **не может начаться раньше**, чем завершится A.
- Один процесс может зависеть от **нескольких** - тогда он стартует после завершения **всех** своих предшественников.

---

## Идея решения

1. **Построить граф зависимостей**: ребро A → B означает «A должен завершиться до старта B».
2. Для каждого процесса вычислить **время начала** = максимум по всем временам завершения предшественников.
3. **Время завершения** процесса = время начала + его длительность.
4. **Ответ** = максимум времён завершения среди всех процессов.

Этот метод называется **нахождением критического пути** (метод CPM).

---

## Алгоритм по шагам

1. Прочитать таблицу: для каждого процесса знаем его длительность и список предшественников.
2. Обработать процессы **в топологическом порядке** (сначала независимые, потом зависящие от них).
3. Для каждого процесса:
   - Если предшественников нет → `start = 0`
   - Иначе → `start = max(finish[p] for p in predecessors)`
   - `finish = start + duration`
4. `Ответ = max(finish[i] for all i)`

---

## Пример

**Таблица процессов:**

| ID | Время (мс) | Предшественник |
|:---:|:---:|:---:|
| 1 | 10 | 0 |
| 2 | 20 | 0 |
| 3 | 15 | 1 |
| 4 | 5  | 2 |
| 5 | 25 | 3, 4 |

**Граф зависимостей:**
```
1 ──(10)──► 3 ──(15)──► 5
2 ──(20)──► 4 ──(5)───►/
```

**Расчёт:**

| ID | Длит. | Предш. | start | finish |
|:---:|:---:|:---:|:---:|:---:|
| 1 | 10 | - | 0 | **10** |
| 2 | 20 | - | 0 | **20** |
| 3 | 15 | 1 | 10 | **25** |
| 4 | 5  | 2 | 20 | **25** |
| 5 | 25 | 3,4 | max(25,25)=25 | **50** |

**Ответ: 50 мс**

Критический путь: 2 → 4 → 5 (или 1 → 3 → 5, оба дают 50).

---

## Решение на Python

```python
def solve(processes):
    # processes = {id: (duration, [predecessors])}
    finish = {}
    # Топологический обход (простой, если ID уже в порядке зависимостей)
    for pid in sorted(processes):
        duration, preds = processes[pid]
        if not preds:
            start = 0
        else:
            start = max(finish[p] for p in preds)
        finish[pid] = start + duration
    return max(finish.values())

# Пример из таблицы выше
processes = {
    1: (10, []),
    2: (20, []),
    3: (15, [1]),
    4: (5,  [2]),
    5: (25, [3, 4]),
}
print(solve(processes))  # 50
```

## Чтение из файла (типичная структура ЕГЭ)

```python
# Формат файла: ID время предшественник (0 если нет)
# Один предшественник на строку; если несколько - несколько строк с тем же ID

from collections import defaultdict

preds = defaultdict(list)
duration = {}

with open("input.txt") as f:
    for line in f:
        parts = line.split()
        pid, dur, pre = int(parts[0]), int(parts[1]), int(parts[2])
        duration[pid] = dur
        if pre != 0:
            preds[pid].append(pre)

# Топологический порядок через DFS
visited = {}

def finish_time(pid):
    if pid in visited:
        return visited[pid]
    if not preds[pid]:
        start = 0
    else:
        start = max(finish_time(p) for p in preds[pid])
    visited[pid] = start + duration[pid]
    return visited[pid]

for pid in duration:
    finish_time(pid)

print(max(visited.values()))
```

---

## Типичные ошибки

| Ошибка | Как избежать |
|:---|:---|
| Забыть, что процесс ждёт **всех** предшественников | Брать `max`, а не `sum` времён завершения |
| Считать, что независимые идут последовательно | Независимые процессы стартуют одновременно в момент 0 |
| Неправильный топологический порядок | Использовать рекурсию или очередь (BFS по источникам) |
