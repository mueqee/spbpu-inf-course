# Задание 22: Анализ выполнения вычислительных процессов

## Общая информация

- **Тема:** параллельное и последовательное выполнение процессов, минимальное время выполнения совокупности работ.
- **Формат данных:** таблица (файл) с колонками: ID процесса, время выполнения (мс), ID зависимых процессов (0 если независимый).
- **Ответ:** минимальное время завершения всех процессов при оптимальном расписании.

## Правила

- Процессы не приостанавливаются.
- Независимые процессы выполняются параллельно.
- Если процесс B зависит от процесса A, то A и B выполняются последовательно (сначала A, потом B).

## Идея решения

- Построить граф зависимостей (кто от кого зависит).
- Учесть порядок выполнения: процесс запускается только после завершения всех, от кого он зависит.
- Найти критический путь или смоделировать расписание и вычислить минимальное суммарное время (или время до завершения последнего процесса).

## Структура папки

- **Теория**: этот файл.
- **Задания/**: тексты задач, примеры таблиц.
- **Решения/**: примеры решений на Python (разбор зависимостей, расчёт времени).
