### Кодирование текстовой информации

```
V = n * i
```

``` python
def V(n, i):
	return n * i
```
где:
- **n** — количество символов
- **i** — количество бит на 1 символ (кодировка)

### Формулы преобразования:

```
1 Гбайт = 2^30 байт = 2^33 бит.
1 Мбайт = 2^20 байт = 2^23 бит,  
1 Кбайт = 2^10 байт = 2^13 бит
```

### Формула для нахождения количества цветов в используемой палитре:

```
i = log2N
```

где:
- **N** — количество цветов
- **i** — глубина цвета

Или получаем:
```
N = 2^i
```

```python
def N(i):
	return pow(2, i)
```

Глубина кодирования/цвета это объем одного пикселя
### Кодирование звуковой информации

Для хранения информации о звуке длительностью _t_ секунд, закодированном с частотой дискретизации _ƒ_ Гц и глубиной кодирования _β_ бит требуется бит памяти:
```
I = β * ƒ * t * S
```

где:
- **I** — объем
- **β** — глубина кодирования
- **ƒ** — частота дискретизации
- **t** — время
- **S** — количество каналов

_S_ для моно _= 1_, для стерео _= 2_, для квадро _= 4_
1 кГц = 1000 Гц

Как такового шаблона нет, но алгоритм решения руками легко реализуем кодом

```python
from math import *

c = set()

for b in range(1, 10000):
	a = 768 * 600
	i = ceil(log2(b)) # Округляем в большую сторону, так как биты только целые. Если округлим в меньшую сторону, то мы потеряем часть информации
	if a * i / pow(2, 13) <= 420:
		c.add(b)

print(max(c))
```
