### Основные команды

```python
from turtle import *

forward(n) # Передвигает на n пикселей вперед
backward(n) # Передвигает на n пикселей назад
right(n) # Поворачивает вправо на n градусов
left(n) # Поворачивает влево на n градусов
goto(x, y) # Перемещает в заданные координаты
dot(n) # Рисует точку с диаметром n пикселей
up() # Поднять хвост (черепаха перестает оставлять след)
down() # Опустить хвост (черепаха оставляет след)

```

### Задача 1

Нахождение периметра пересечения двух фигур

```python
from turtle import *

tracer(0)

m = 30 # Вводим масштаб в виде переменной, т.к рисунок слишком мелкий
# Углы умножать не надо, они всегда одинаковые

  
for i in range(9):
	forward(22 * m)
	right(90)
	forward(6 * m)
	right(90)

up()

forward(1 * m)
right(90)
forward(5 * m)
left(90)

down()

for i in range(9):
	forward(53 * m)
	right(90)
	forward(75 * m)
	right(90)

up()

for x in range(-25, 25):
```
