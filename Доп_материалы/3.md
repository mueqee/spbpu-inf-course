# Задание 3 - Поиск информации в реляционных базах данных

Время экономит решение через ВПР (аналог join в SQL).

```
=ВПР(Значение; $Таблица; Номер столбца; 0)
```

Параметры:
- Первый: по какому значению перетаскивать значение (по ID)
- Второй: откуда забирать значение (из какой таблицы, таблицы выделяем полностью, вдоль названий столбцов)
- Третий: порядковый номер столбца (в каком столбце таблицы находится нужное значение)
- Четвертый: всегда 0
