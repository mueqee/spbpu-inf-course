Пример задачи:

```
Откройте файл электронной таблицы, содержащей в каждой строке три натуральных числа.
Выясните, какое количество троек чисел может являться сторонами треугольника, то есть удовлетворяет неравенству треугольника. В ответе запишите только число.
```

```python
k = 0

for s in open('09.txt'):
    '''
    Треугольник существует, если сумма длин двух его меньших сторон больше длины самой большой стороны.
    Отсюда необходимо отсортировать по возрастанию и обращаться к числам по индексу
    '''
    a = sorted([int(x) for x in s.split()])
    if a[0] + a[1] > a[2]:
        k += 1

print(k)
```
