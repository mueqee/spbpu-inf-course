```python
from itertools import * # Импортируем библиотеку

# Каждый символ используется единожды в строке, порядок важен
for i in permutations('ABC', 2): # Передаем итерируемый объект и длина выборки
print(i)

# Каждый символ используется любое количество раз в строке, порядок важен
for i in product('ABC', repeat=2): # Необходимо указать repeat
print(i)
  
# Каждый символ используется единожды в строке, порядок не важен
for i in combinations('ABC', 2):
print(i)

# Чаще всего попадаются permutations и product
```
## Слова по порядку
Пример задачи:
```
Все 5-⁠буквенные слова, составленные из букв Л, Н, Р, Т, записаны в алфавитном порядке. Вот начало списка:
1.  ЛЛЛЛЛ
2.  ЛЛЛЛН
3.  ЛЛЛЛР
4.  ЛЛЛЛТ
5.  ЛЛЛНЛ
 
Запишите слово, которое стоит на 150-⁠м месте от начала списка.
```
```python
from itertools import *

k = 0 # Вводим счетчик слов
'''
Так как буквы могут повторяться сколько угодно раз, применяем product,
необходимо отсортировать заданные буквы по алфавиту (условие),
вместо ручной сортировки можно использовать функцию sorted,
она предназначена не только для чисел.
По условию 5-буквенные слова, соответственно, repeat=5
'''

for i in product(sorted('ЛНРТ'), repeat=5):
    a = ''.join(i) # без join выражение будет выглядеть как ('Л', 'Л', 'Л', 'Л', 'Л')
    k += 1 # Каждый раз прибавляем один
    if k == 150: # По условию нужно слово на 150 месте, значит, выводим выражение, если k = 150
        print(a)

```
```
Все 5-⁠буквенные слова, составленные из букв А, О, У, записаны в алфавитном порядке. Вот начало списка:
1.  ААААА
2.  ААААО
3.  ААААУ
4.  АААОА
...

Укажите номер слова УАУАУ.
```
```python
from itertools import *

k = 0

for i in product(sorted('АОУ'), repeat=5):
    a = ''.join(i)
    k += 1
    if a == 'УАУАУ':
        print(k)
```


## Подсчет количества разных последовательностей
Примеры задач:
```
Составляют 5-⁠буквенные слова из букв слова ПЯТНИЦА. Найти количество слов, которые не начинаются с Н и в которых есть только одна буква Я. Буквы в слове могут повторяться.
```
```python
from itertools import *

k = 0

for i in product('ПЯТНИЦА', repeat=5):
    a = ''.join(i)
    if a[0] != 'Н' and a.count('Я') == 1:
        k += 1

print(k)
```

```
Сколько существует чисел, восьмеричная запись которых содержит 5 цифр, причем в записи нет цифры 1. Также все цифры записи различны и никакие две чётные и две нечётные цифры не стоят рядом.
```
```python
from itertools import *

k = 0

for i in permutations('01234567', r=5):
    a = ''.join(i)
    if a[0] != '0' and a.count('1') == 0:
        # Проверяем пару соседних цифр на разную четность, должно получиться 10101 или 01010
        if int(a[0])%2 != int(a[1])%2 and int(a[1])%2 != int(a[2])%2 and int(a[2])%2 != int(a[3])%2 and int(a[3])%2 != int(a[4])%2:
            k += 1
print(k)
```
или проще:

```python
from itertools import *

k = 0

for i in permutations('01234567', r=5):
    a = ''.join(i)
    if a[0] != '0' and a.count('1') == 0:
        if all(int(x) % 2 != int(y) % 2 for x, y in zip(a, a[1:])):
            k += 1
print(k)
```

```
Алиса составляет 6-⁠буквенные слова из букв М, А, Н, Г, У, С, Т. Каждая из букв может встречаться сколько угодно раз, причём первой буквой не может быть А, буква У должна встречаться не менее 1 раза. Также в записи должны быть ровно две буквы М.

Сколько различных слов может составить Алиса?
```
```python
from itertools import *

k = 0

for i in product('МАНГУСТ', repeat=6):
    a = ''.join(i)
    if a[0] != 'А' and a.count('У') >= 1 and a.count('М') == 2:
        k += 1
print(k)
```

## Подсчет количества слов с ограничениями
Пример задачи:
```
Игорь составляет таблицу кодовых слов для передачи сообщений, каждому сообщению соответствует своё кодовое слово. В качестве кодовых слов Игорь использует 5-⁠буквенные слова, в которых есть только буквы П, И, Р, причём буква П появляется ровно 1 раз. Каждая из других допустимых букв может встречаться в кодовом слове любое количество раз или не встречаться совсем. Сколько различных кодовых слов может использовать Игорь?
```

```python
from itertools import *

k = 0

for i in product('ПИР', repeat=5):
    a = ''.join(i)
    if a.count('П') == 1:
        k += 1

print(k)
```

### Задача 1

```python
from itertools import *

s = set() # Множество сохраняет только уникальные элементы

for i in permutations('МАРИНА', 6):
	a = ''.join(i)
	if a[0] not in 'АИ':
	s.add(a) # Все неуникальные значения сохранятся только по одному разу

print(len(s))
```
