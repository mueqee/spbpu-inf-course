```python
from re import finditer # Паттерн, строка - все вхождения подстрок, подходящие под регулярку

# Регулярные выражения удобнее записывать в неэкранированные строки

# Пример: r'[a-z]+\.[a-z]+'
```

Квантификаторы:
- * или больше:
	- A* - Пустота или буква А
- + один или более:
	-  А+ - Буквы А (от 1 до бесконечности)
- {n} ровно n количество раз:
	- А{5} - ААААА
- {n, g} от n до g
	- A{2, 4} - АА, ААА, АААА

Символьные классы
- [ABC] один из символов:
	- [ABC]{4} - BCAA, CABB
- [A-Z] один символ из заданного диапазона:
	- [0-9] {3} - 132, 234, 948, 007
- [^ABC] не А, не В, не С

. - любой непроизвольный символ

ВАЖНО: если служебные символы проверяются  как обычные, то перед ними надо поставить \ (\. \+ \{)

```python
from re import finditer

s = open('24.txt').readline # Читаем строку

reg = r'[ABC]+'

print(max(len(x.group()) for x in finditer(reg, s)))

# .group() возвращает совпадения
```

Скобочные группы
- () - группировка символов
	- (AB) - уже как один символ, пары идут подряд
- (?=(...)) - поиск всех возможных совпадений с учетом пересечений
	-  В таком случае нужно будет писать x.group(1)

Перечисления
- AB|CD|DE - AB или CD или DE

```python
from re import finditer

s = open('24.txt').readline # Читаем строку
# Порядок важен, поэтому лучше писать сначала то, что длинее
reg = r'(ZX|ZY)+' # Читается как: пара 1 или 2 повторяется какое-то кол-во раз

print(max(len(x.group()//2 for x in finditer(reg, s)))) # Делим на 2, ибо условию кол-во пар, а не символов
```

```python
from re import finditer

s = open('24.txt').readline
reg = r'([BCD][AO])+' # По условию нам нужна пара согласная + гласная

print(max(len(x.group()//2 for x in finditer(reg, s))))
```
