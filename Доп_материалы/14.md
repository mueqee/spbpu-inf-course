Цикл для перевода в систему счисления (на примере вторая система)

```python
x = 3 * pow(3125, 8) + 2 * pow(625, 7) - 4 * pow(625, 6) + 3 * pow(125, 5) - 2 * pow(25, 4) - 2025
k = 0
while x > 0:
	if x % 25 == 0:
		k += 1
	x = x // 25
print(k)
```
