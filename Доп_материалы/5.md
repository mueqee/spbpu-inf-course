**Важно** - если просят найти минимальный N, то достаточно написать break, так как мы перебираем N через range по порядку. Если просят найти минимальный/максимальный R, то необходимо добавить R в список или множество, только после этого применить функцию min/max. Писать break для минимального R нельзя, так как это результат вычисления N по заданному условию, а значит первый вывод R в терминале может и не являться минимальным.

## Посимвольное двоичное преобразование
Пример задачи:
```
На вход алгоритма подаётся натуральное число N. Алгоритм строит по нему новое число R следующим образом.
1.  Строится двоичная запись числа N.
2.  К этой записи дописываются справа ещё два разряда по следующему правилу:
а)  складываются все цифры двоичной записи, и остаток от деления суммы на 2 дописывается в конец числа (справа). Например, запись 11100 преобразуется в запись 111001;
б)  над этой записью производятся те же действия  — справа дописывается остаток от деления суммы цифр на 2.
Полученная таким образом запись (в ней на два разряда больше, чем в записи исходного числа N) является двоичной записью искомого числа R.
Укажите минимальное число R, которое превышает 43 и может являться результатом работы алгоритма. В ответе это число запишите в десятичной системе.
```
```python
for N in range(1, 200):
    b = bin(N)[2:] # Двоичная запись числа N. Необходим срез, т.к из-за особенностей питона первые два индекса равны "0b" соответственно
    '''
    Двоичная запись состоит из единиц и нулей, 
    а значит, сумма и есть количество единиц
    '''
    b += str(b.count('1') % 2) # Так как значение нужно добавить справа, переводим выражение в str()
    b += str(b.count('1') % 2) 
    R = int(b, 2)
    if R > 43:
        print(R)
        break 
    '''
    В данной задаче в выводе R идут по порядку, 
    поэтому здесь можно использовать break для вывода минимального значения,
    но лучше сразу добавить в [] или set() и обратиться к функции min()
    '''
```

## Посимвольное преобразование в n-ричной системе счисления
Пример задачи:
```
Алгоритм получает на вход натуральное число N и строит по нему новое число R следующим образом.
1.  Строится троичная запись числа N.
2.  В полученной записи все нули заменяются на двойки, все двойки  — на нули. Из полученного числа удаляются ведущие нули.
3.  Результат переводится в десятичную систему счисления.
4.  Результатом работы алгоритма становится модуль разности исходного числа N и числа, полученного на предыдущем шаге.
При каком наименьшем N в результате работы алгоритма получится R  =  1 864 246.
```

```python
def f(N):
    x = ''
    while N > 0:
        x = str(N % 3) + x
        N //= 3
    return x

for N in range(1, 5000000):
    b = f(N)
    b = b.replace('0', '*').replace('2', '0').replace('*', '2')
    '''
    Если записать так:
    b.replace('0', '2').replace('2', '0')
    то наглядно видно, что правильный ответ мы не получим. Одно из значений нужно изменить на любой удобный символ
    '''
    b = b.lstrip('0') # Данная функция автоматически удаляет все ведущие нули
    if b == '': 
        b = '0' # Строка может оказаться пустой. Корректно будет добавить 0. Единственный 0 не является ведущим
    R = abs(N - int(b, 3))
    if R == 1864246:
        print(N)
        break
```

## Посимвольное десятичное преобразование
Пример задачи:
```
Автомат получает на вход трёхзначное число. По этому числу строится новое число по следующим правилам.
1.  Складываются первая и вторая, а также вторая и третья цифры исходного числа.
2.  Полученные два числа записываются друг за другом в порядке убывания (без разделителей).
Пример. Исходное число: 348. Суммы: 3 + 4  =  7; 4 + 8  =  12. Результат: 127. Укажите наименьшее число, в результате обработки которого автомат выдаст число 1412.
```

for N in range(100, 1000):
