def f(s, m): # s - кол-во камней в куче, m - кол-во оставшихся ходов
    if s >= 39: # Условие победы по условию
        return m % 2 == 0
    if m == 0:
        return 0
    # Заполняем список по условию,
    h = [f(s + 1, m - 1), f(s + 3, m - 1), f(s * 2, m -1)] # Всевозможные ходы
    return any(h) if m % 2 != 0 else all(h)

'''
Перебираем все ходы, по условию от 1 до 38 включительно

По условию Ваня должен выиграть первым ходом, первый ход за Петей,
то есть Ваня ходит после Пети, а значит это второй ход,
поэтому пишем if f(s, 2)
'''
print([s for s in range(1, 39) if f(s, 2)])

'''
По условию Петя не может выиграть за один ход, а также может

'''
print([s for s in range(1, 39) if not f(s, 1) and f(s, 3)])
