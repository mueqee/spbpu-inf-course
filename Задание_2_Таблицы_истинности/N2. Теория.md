## 1. Основные логические операции

| Операция                  | Обозначение    | Python          | Таблица истинности               | Когда истинно                |
| ------------------------- | -------------- | --------------- | -------------------------------- | ---------------------------- |
| **Отрицание (НЕ)**        | ¬A, NOT A      | `not A`         | A = 0 → ¬A = 1<br>A = 1 → ¬A = 0 | Когда A = 0                  |
| **Конъюнкция (И)**        | A ∧ B, A AND B | `A and B`       | 0∧0=0, 0∧1=0<br>1∧0=0, 1∧1=1     | Только при A=1 и B=1         |
| **Дизъюнкция (ИЛИ)**      | A ∨ B, A OR B  | `A or B`        | 0∨0=0, 0∨1=1<br>1∨0=1, 1∨1=1     | Когда хотя бы одно = 1       |
| **Импликация**            | A → B          | `not A or B`    | 0→0=1, 0→1=1<br>1→0=0, 1→1=1     | Ложь только при 1→0          |
| **Эквиваленция**          | A ↔ B, A ≡ B   | `A == B`        | 0↔0=1, 0↔1=0<br>1↔0=0, 1↔1=1     | Когда значения одинаковы     |
| **Исключающее ИЛИ (XOR)** | A ⊕ B          | `A != B`        | 0⊕0=0, 0⊕1=1<br>1⊕0=1, 1⊕1=0     | Когда значения различны      |
| **Штрих Шеффера (NAND)**  | A ↑ B, A       | `not (A and B)` | 0↑0=1, 0↑1=1<br>1↑0=1, 1↑1=0     | Ложь только при A=1 и B=1    |
| **Стрелка Пирса (NOR)**   | A ↓ B          | `not (A or B)`  | 0↓0=1, 0↓1=0<br>1↓0=0, 1↓1=0     | Истинно только при A=0 и B=0 |

## 2. Приоритет операций

**От высшего к низшему:**
1. **Отрицание** (¬) имеет самый высокий приоритет
2. **Конъюнкция** (∧)
3. **Дизъюнкция** (∨)
4. **Импликация** (→)
5. **Эквиваленция** (↔) имеет самый низкий приоритет

**Пример:** ¬A ∨ B ∧ C = (¬A) ∨ (B ∧ C)

## 3. Законы булевой алгебры (для упрощения)

### 3.1. Основные законы

| Закон | Формула |
|-------|---------|
| **Тождества** | A ∧ 1 = A; A ∨ 0 = A |
| **Нуля и единицы** | A ∧ 0 = 0; A ∨ 1 = 1 |
| **Дополнения** | A ∧ ¬A = 0; A ∨ ¬A = 1 |
| **Идемпотентности** | A ∧ A = A; A ∨ A = A |
| **Поглощения** | A ∨ (A ∧ B) = A; A ∧ (A ∨ B) = A |
| **Коммутативности** | A ∧ B = B ∧ A; A ∨ B = B ∨ A |
| **Ассоциативности** | (A ∧ B) ∧ C = A ∧ (B ∧ C) |
| **Дистрибутивности** | A ∧ (B ∨ C) = (A ∧ B) ∨ (A ∧ C) |

### 3.2. Законы де Моргана

| Закон | Формула |
|-------|---------|
| **Отрицание конъюнкции** | ¬(A ∧ B) = ¬A ∨ ¬B |
| **Отрицание дизъюнкции** | ¬(A ∨ B) = ¬A ∧ ¬B |

### 3.3. Преобразование импликации

$$A \to B = \neg A \vee B$$

**Важно!** самое частое преобразование в **задачах** ЕГЭ

### 3.4. Преобразование штриха Шеффера и стрелки Пирса

**Штрих Шеффера (NAND):**
$$A \uparrow B = \neg(A \wedge B) = \neg A \vee \neg B$$

**Стрелка Пирса (NOR):**
$$A \downarrow B = \neg(A \vee B) = \neg A \wedge \neg B$$

**Выражение через базовые операции:**
$$A \uparrow B = \neg(A \wedge B)$$ (отрицание конъюнкции)
 $$A \downarrow B = \neg(A \vee B)$$ (отрицание дизъюнкции)

**Обратные преобразования:**
 $$A \wedge B = \neg(A \uparrow B) = (A \uparrow A) \uparrow (B \uparrow B)$$$$A \vee B = \neg(A \downarrow B) = (A \downarrow B) \downarrow (A \downarrow B)$$

## 4. Общий шаблон решения задач на определение соответствия столбцов

### Тип задачи: Определение порядка переменных в таблице истинности

**Условие:** Дано логическое выражение и несколько строк таблицы истинности с частично заполненными значениями. Нужно определить, какой столбец соответствует какой переменной.

### Алгоритм решения:

**Шаг 1: Преобразовать логическое выражение в Python-код**

| Логическая операция | Python |
|---------------------|--------|
| $$A \to B$$ | `not A or B` |
| $$\neg A$$ | `not A` |
| $$A \wedge B$$ | `A and B` |
| $$A \vee B$$ | `A or B` |
| $$A \leftrightarrow B$$ | `A == B` |
| $$A \uparrow B$$ (штрих Шеффера) | `not (A and B)` |
| $$A \downarrow B$$ (стрелка Пирса) | `not (A or B)` |

**Шаг 2: Написать код для перебора всех комбинаций**

```python
for w in [0, 1]:
    for x in [0, 1]:
        for y in [0, 1]:
            for z in [0, 1]:
                if (выражение) == заданное_значение:
                    print(переменные_в_нужном_порядке, значение)
```

**Шаг 3: Определить порядок вывода переменных**

Порядок переменных в `print()` определяет порядок столбцов в ответе.

**Примеры из задач:**

**Пример 1:** `F = (x→y)∧z∧¬w`, найти наборы, где F = 1
```python
print('w x y z F')  # Порядок вывода
for w in [0,1]:
    for x in [0,1]:
        for y in [0,1]:
            for z in [0,1]:
                if ((not x or y) and z and (not w)) == 1:
                    print(w, x, y, z, 1)
# Ответ: yzxw (порядок столбцов определяется по данным строкам)
```

**Пример 2:** `F = (y→x)∧¬z∧w`, найти наборы, где F = 1
```python
for x in [0,1]:
    for y in [0,1]:
        for z in [0,1]:
            for w in [0,1]:
                if ((not y or x) and (not z) and w) == 1:
                    print(w, x, y, z, 1)
# Ответ: wxyz
```

**Пример 3:** `F = ¬(w→x)∨(y→z)∨¬y`, найти наборы, где F = 0
```python
for x in [0,1]:
    for z in [0,1]:    
        for w in [0,1]:
            for y in [0,1]:
                if ((not (not w or x)) or (not y or z) or (not y)) == 0:
                    print(y, x, w, z, 0)
# Ответ: yxwz
```

**Пример 4:** `F = ¬x∨y∨(¬z∧w)`, найти наборы, где F = 0
```python
for w in [0,1]:
    for x in [0,1]:
        for y in [0,1]:
            for z in [0,1]:
                if ((not x) or y or ((not z) and w)) == 0:
                    print(w, x, y, z, 0)
# Ответ: wxzy
```

**Пример 5:** `F = (x→y)∨¬(w→z)`, найти наборы, где F = 0
```python
for w in [0,1]:
    for x in [0,1]:
        for y in [0,1]:
            for z in [0,1]:
                if (((not x) or y) or (w and (not z))) == 0:
                    print(w, x, y, z, 0)
# Ответ: zywx
```

### Ключевые моменты:

1. **Преобразование импликации:** $$A \to B = \neg A \vee B$$
2. **Отрицание импликации:** $$\neg(A \to B) = A \wedge \neg B$$
3. **Порядок переменных в print()** определяет порядок столбцов в ответе
4. **Нужно найти все наборы**, где функция принимает заданное значение (0 или 1)
5. **Сопоставить** найденные наборы с данными строками таблицы для определения порядка
